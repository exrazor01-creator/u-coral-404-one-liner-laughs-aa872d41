A single original one-liner for the One-Liner Laughs bounty: I ask my AI assistant to make me funnier, and it sighs that it will need a bigger model for that. The setup sounds like an ordinary request to a helpful chatbot, and the payoff flips the roles — the supposedly tireless assistant sighs like a tired human and blames the hardware, turning a real AI term into a put-down aimed at the speaker.

## Run it

```sh
python3 main.py
```

This validates the line (1–200 characters, ASCII only, single line) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
